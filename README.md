# 🫧 Steal a Slime! — движок «фабрики плейсов»

Игра целиком в коде: карта, слаймы, UI, экономика, монетизация. Новый плейс на этом движке =
новый `Config.luau` + `Pets.luau` + тема карты в `MapBuilder.luau`.

## Как играется
- Слаймы выезжают из портала по дороге → покупаешь → он прыгает на твою базу и приносит $/сек.
- Можно **украсть** слайма с чужой базы (зажать E) и донести до своей. Хозяин может догнать и **бонкнуть битой** — слайм вернётся.
- **Замок базы** (кнопка на полу или в меню) — 60 сек защиты.
- Прокачка скорости, ребёрты (+50% дохода навсегда), ежедневная награда со стриком, офлайн-доход.
- Редкости Common → Secret, варианты GOLD (x3) и RAINBOW (x8), объявления на весь сервер о редких спавнах.

## Монетизация
| Тип | Что |
|---|---|
| Game Pass | 2x Cash, VIP, +4 слота, Mega Lock |
| Dev Product | Cash Pack, Cash Vault (масштабируются от дохода), Lucky Spawn, Server Luck x2 |

Покупки защищены от двойной выдачи (история чеков), сохранения — от дюпа между серверами (сессионный лок).

## Автоматика без участия человека
- **Авто-ивенты по расписанию** (`Config.Schedule`): Lucky Rain, Golden Rush, Cash Storm — крутятся сами.
- **LiveOps** (`tools/liveops.sh`): мгновенно меняем удачу/доход/объявления на всех серверах.
- **Автодеплой** (`.github/workflows/deploy.yml`): push в репозиторий → игра собирается и публикуется.
- **Режим съёмки шортсов**: F6 — спрятать UI, F7 — кинокамеры (облёт, слежка за редким слаймом, пролёт).

## Разовая настройка (≈15 минут)
1. Создать игру на create.roblox.com (можно пустой Baseplate), в настройках: **Max Players = 8**,
   включить **Studio Access to API Services**. Записать **Universe ID** и **Place ID**.
2. Open Cloud → API Keys → ключ с правами `universe-places:write` и
   `universe-messaging-service:publish` для этой игры.
3. Репозиторий на GitHub с этим проектом → Secrets: `ROBLOX_API_KEY`, `UNIVERSE_ID`, `PLACE_ID`.
4. Вписать свой UserId в `Config.Admins` (для камеры шортсов).
5. Позже: создать пассы/продукты и вписать ID в `Config.GamePasses` / `Config.Products`.

## Локальная проверка
```
rojo build -o game.rbxl        # собрать
rojo serve                     # live-sync в Studio (плагин Rojo)
```
